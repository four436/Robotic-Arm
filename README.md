# Robotic Arm
Este un braț robotic pe 5 axe, realizat in iunie 2025.
Acesta conține 4 servo motoare mg996r (20kg) pentru segmente, un servo motor sg90 pentru clește și un motor pas cu pas NEMA 17 pentru baza acestuia.Inafară de rulmentul bazei toate piesele sunt printate 3d din ABS pentru a oferi o rezistență și duritate mai ridicată. Brațul are un arduino Giga R1 pentru a putea fi controlat, alimentat de o sursa de 150W, proto-pcb-ul este pentru a reduce din interferențe, a nu pierde din puterea oferită de sursă (din cauza firelor lungi) și a putea conecta mai ușor brațul la microcontroller.
